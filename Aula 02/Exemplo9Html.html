Exemplo 9 - Links e Tabelas

Descrição

Este exemplo mostra como criar tabelas e links em HTML, nele também utilizamos a estrutura da web semântica, que tem um papel muito importante para na indexação de conteúdos pelos mecanismos de busca. Neste exemplo estamos usando as tags semânticas <header>,<footer>, <section>, <nav>, <article>.

Também uilizamos as tags para criação dos links e tabelas que são descritos a seguir:

  • <a> Define um hiperlink
  • <table> Define uma tabela
  • <tr> Define uma linha da tebela - table row
  • <th> Define um cabeçalho da tabelas - table header
  • <td> Define uma célula da tabela - table data

Exemplos de links que abrem uma nova aba:

  • Visite o Google
  • Visite o CNN
  • Explore projetos no GitHub
  • Veja videos no Youtube
