Exemplo 6 HTML - Principais elementos elementos

Tags: <p>, <hr>, <br>, <strong>, <em>, <b>, <i>, etc...

A seguir vamos descrever alguns dos principais elementos html, que são definidos por tags. Por exemplo:

<p> Essa tag define um parágrafo. É um bloco, o navegador vai interpretar e dar um espaço antes e depois.

<hr> A tag hr cria uma linha horizontal, é utilizada para separar assuntos.

<br> A tag br é utilizada para quebra de linha dentro de um mesmo parágrafo.

<strong> A tag strong renderiza o elemento em negrit, e tem importância semântica.

<em> Essa tag renderiza a palavra em itálico e também tem valor semântico.

<b> Essa tag renderiza a palavra em negrito.

<i> Essa tag renderiza a palavra em itálico.

<mark> A tag mark é utilizada para dar destaque em uma palavra ou texto, e funciona como um marca texto. Exemplo: Lorem ipsum dolor sit, amet consectetur adipisicing elit. Officia inventore doloremque blanditiis est explicabo cum sequi molestias sit aperiam quibusdam. Architecto, totam laboriosam deleniti animi omnis ea? A, maxime quia?
