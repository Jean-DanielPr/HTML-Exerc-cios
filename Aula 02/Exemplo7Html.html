Exemplo 7 HTML - Listas

em documentos html podemos usar 3 listas distintas são elas: lista ordenada. lista não ordenada e lista descritiva. Essas listas são representadas pelas tags: <ol>, <ul>, e <dt/dl/dt>. Para todas as listas utilizamos a tag <li>, que representa um iteme só pode ser utilizado demtrp das çoistas ordenadas ou não ordenadas.

Lista ordenada - <ol>

Neste tipo de lista os elementos são distribuídos em ordem ou seja, a ordem importa. Por exemplo:

  1. Planejamento
  2. Design
  3. Desenvolvimento
  4. Testes
  5. Publicação

Lista não ordenada - <ul>

Esse tipo de lista não possui uma ordem específica e seues elementos são representados por bullets. Essa lista é muito utilizada para construção de menus. Por exemplo:

  • HTML
  • CSS
  • JavaScript
  • Outras tecnologias
