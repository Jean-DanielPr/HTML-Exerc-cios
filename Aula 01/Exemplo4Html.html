Introdução ao HTML

O HTML é uma linguagem de marcação que utiliza tags para exibir informações em documentos html.

O HTML está na versão 5 e é atualmente o padrão estrutural para criar páginas na internet. Ele funciona como esqueleto de um site, organizando textos, imagens, vídeos, links para que o navegador consiga interpretar e exibir tudo corretamente.

Estrutura de uma página html.

Documentos html possuem uma estrutura basilar centrado nas tags: <html>, <head>, <body>
